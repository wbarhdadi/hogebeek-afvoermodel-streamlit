Can every cubic metre be accounted for?

This demo tests the proposed timestep and coupling state model: every rainfall interval is consumed, effective water waits in explicit travel queues, upstream outflow reaches the downstream subcatchment one interval later, and the ledger always balances.

What to challenge: Should rainfall timestamps mark interval starts? Should upstream transfer wait one interval? Should a run continue with dry drain intervals? Use the walkthroughs, then compare the proposed model with the legacy “skip first rainfall” behavior.
